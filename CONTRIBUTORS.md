# Contributors

People whose code has landed in Masar X, with the PRs that carry it. Merged pull requests keep their author; when a fork pull request cannot run the repository's required checks and is superseded upstream, the original author is credited with a `Co-authored-by:` trailer **and** a row here — never silently. See [CONTRIBUTING.md → Credit & recognition](./CONTRIBUTING.md#credit--recognition).

**Machine-readable registry:** [`contributors/emails/`](./contributors/emails/) holds one file per contributor email, named for the email their landed commits use, whose content is their GitHub handle. New contributors add a table row here **and** an email file. (Convention follows the practice of projects like [`NousResearch/hermes-agent`](https://github.com/NousResearch/hermes-agent).)
